# Crypto Price Tracker & Analytics Dashboard

A full-stack, multi-language portfolio project combining a **Python** real-time data collector with a **Java Spring Boot** REST API backend and an interactive **HTML/JavaScript** dashboard.

---

## Architecture & Workflow

```text
[ Binance Spot API ] 
        │  (Python requests - every 10s)
        ▼
[ crypto_prices.csv ] 
        │  (Java BufferedReader & Streams)
        ▼
[ Spring Boot REST API ] 
        │  (JSON Endpoints)
        ▼
[ Web Dashboard (HTML/JS) ]  <── Auto-refreshes every 10s
```

1. **Data Ingestion (Python):** Fetches real-time market prices for `BTCUSDT` and `ETHUSDT` from the public Binance Spot REST API every 10 seconds and appends timestamped records to a local CSV file.
2. **Backend & Analytics (Java + Spring Boot):** Reads and parses the CSV file, filters records by cryptocurrency symbol, and computes real-time summary statistics (count, minimum, maximum, and average price) using Java Streams (`DoubleSummaryStatistics`).
3. **Frontend Visualization (HTML5, CSS3, Vanilla JS):** Responsive dashboard that consumes the Java REST endpoints asynchronously (`fetch`) and automatically refreshes every 10 seconds with a toggleable auto-refresh control.

---

## Tech Stack

* **Data Collector:** Python 3, `requests`, `csv`, `datetime`
* **Backend Framework:** Java 25/26, Spring Boot 4.1.2 (Spring Web), Maven
* **Frontend:** HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript (ES6+)
* **External API:** Binance Public Spot API (`/api/v3/ticker/price`)

## REST API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/crypto/status` | Health check confirming the Spring Boot server is running. |
| `GET` | `/api/crypto/prices` | Returns all historical price records stored in the CSV file. |
| `GET` | `/api/crypto/prices/{symbol}` | Filters price history by symbol (e.g., `BTCUSDT`, `ETHUSDT`). |
| `GET` | `/api/crypto/stats/{symbol}` | Calculates count, min, max, and average price for a symbol. |

## How to Run Locally

### 1. Start the Python Data Collector
Ensure you have Python 3 and the `requests` library installed:
```bash
pip install requests
python crypto_collector.py
```
*Leave this terminal running so it continuously collects live prices every 10 seconds (`Ctrl + C` to stop).*

### 2. Start the Java Spring Boot Backend
Open a second terminal inside the `java_backend` directory and run:
```bash
cd java_backend
./mvnw spring-boot:run
```
*(On Windows PowerShell, use `.\mvnw.cmd spring-boot:run`)*

> **Note:** Verify that `filePath` inside `CryptoService.java` points to the exact location of your `crypto_prices.csv` file (e.g., `../crypto_prices.csv`).

### 3. Open the Dashboard
Open your browser and navigate to:
```text
http://localhost:8080/
```
